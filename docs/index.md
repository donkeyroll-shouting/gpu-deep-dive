# GPU Deep Dive

Welcome. This site is a growing set of notes on GPU architecture, programming models, and performance.

## What to explore

- GPU execution and memory hierarchy
- CUDA and parallel programming concepts
- Profiling and optimization techniques

## Run locally

```bash
python -m pip install -r requirements.txt
mkdocs serve
```

Open the local address printed by MkDocs (normally <http://127.0.0.1:8000>). Changes to the documentation reload automatically.
